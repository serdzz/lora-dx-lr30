# LoRa Speed vs Range — DX-LR30 (SX1262, 433 МГц)

Связь Spreading Factor → чувствительность → дальность → скорость → энергозатраты.
Цифры приведены для **нашей конфигурации**: SX1262 high-power PA @ +22 dBm,
BW = 125 кГц, CR = 4/5, preamble = 8 символов, payload = 12 байт, антенна 1/4λ.

## Физика в одной строке

Каждый шаг SF удваивает время на символ и добавляет **~2.5 dB** к чувствительности
приёмника (бит-энергия распределяется по двойному chip-периоду, демодулятор
интегрирует дольше — извлекает сигнал из-под более глубокого шума).

## Дальность по средам (с +14 dB при SF12 vs SF7)

В свободном пространстве каждые **6 dB удваивают дальность** (path loss ~ `20·log10(d)`).
+14 dB на переходе SF7→SF12 ≈ **2.3 удвоения = 5× по теории**. В реальной среде
3-5× из-за нелинейных потерь (многолучёвка, листва, рельеф).

| Окружение                        | SF7         | SF12          |
|----------------------------------|-------------|---------------|
| Плотный город (бетон, металл)    | 0.5–1.5 км  | 2–5 км        |
| Пригород, частный сектор         | 2–5 км      | 8–15 км       |
| Открытое поле                    | 5–15 км     | 20–40 км      |
| Чистый LOS (на возвышении)       | 15–30 км    | 50–100+ км    |
| Стратосфера (баллон)             | ~50 км      | до **800 км** |

Цифры — типичные для +22 dBm SX1262 с 1/4λ антенной 433 МГц. Высота установки
антенны над землёй критична: 1 м vs 10 м вверху даёт +10..+15 dB бюджета сама
по себе (Fresnel-зона + Earth-curvature).

## Скорость передачи

Сырая канальная скорость **R_b = SF × BW / 2^SF × CR_ratio**:

| SF | Raw bit-rate | Полезная (12 байт payload, без overhead) |
|----|--------------|------------------------------------------|
| 7  | 5470 bps     | ~7 пакетов/сек → 84 байта/сек            |
| 8  | 3125 bps     | ~4 пакета/сек → 48 байт/сек              |
| 9  | 1758 bps     | ~2.3 пакета/сек → 27 байт/сек            |
| 10 | 977 bps      | ~1.2 пакета/сек → 14 байт/сек            |
| 11 | 537 bps      | ~0.6 пакета/сек → 7 байт/сек             |
| 12 | 293 bps      | ~0.4 пакета/сек → 5 байт/сек             |

SF7→SF12 — **в 18.7× медленнее** по сырой канальной скорости. С учётом
preamble + header overhead для маленьких пакетов разница доходит до 29×.

## Энергозатраты на пакет

SX1262 при +22 dBm TX потребляет ~120 мА. Энергия на пакет = `I_tx × T_oA × V`:

| SF | ToA   | Энергия на ping (3.3 В) | mAh за 1000 пингов |
|----|-------|--------------------------|--------------------|
| 7  | 41 мс | 16.2 мДж                 | 1.37 mAh           |
| 8  | 72 мс | 28.5 мДж                 | 2.40 mAh           |
| 9  | 144 мс| 57.0 мДж                 | 4.80 mAh           |
| 10 | 288 мс| 114 мДж                  | 9.60 mAh           |
| 11 | 659 мс| 261 мДж                  | 21.97 mAh          |
| 12 | 1150 мс| 455 мДж                 | 38.33 mAh          |

SF12 жрёт **в 28× больше** энергии на пакет чем SF7. Если планируешь
портативный полевой тест на пауэрбанке — для SF12 закладывай емкость ×30.

## Duty cycle и регуляторы

ETSI EN 300 220 (EU 868 МГц): max 1% duty cycle в каналах общего назначения.
Это означает: при ToA 1.15 сек (SF12) → минимум **115 секунд паузы между
пакетами**. Иначе нарушение регламента.

**Россия 433 МГц** (ГОСТ Р МЭК 60050) — мягче: для устройств до +10 dBm нет
жёсткого duty cycle, для +22 dBm — серая зона, де-факто никто не контролирует
в полевых SDR-тестах, но юридически SRD-диапазон 433.075–434.775 МГц
ограничен 10 мВт EIRP.

В нашем тесте +22 dBm SF7 даёт ~290 мс эфирного времени/секунду (29% duty cycle).
Для длительной работы стоит снизить до +10 dBm или увеличить паузу между пингами
(сейчас 50 мс).

## Выбор SF для типичных задач

| Задача                                    | Рекомендуемый SF | Почему                |
|-------------------------------------------|------------------|------------------------|
| Bench-test на столе, отладка              | SF7              | Быстрая итерация       |
| Range-test в пригороде (1-5 км)           | SF7-SF9          | Достаточный запас       |
| Range-test за пределами видимости (5-20 км) | SF10-SF11      | Баланс скорость/запас  |

| Низкое энергопотребление per pkt          | SF7              | Минимум ToA            |

## Изменение SF в этой прошивке

Сейчас обе платы пинятся к SF12 (`sf_index = 5` в `node_a.rs:110` и
`node_b.rs:118`). Чтобы переключить:

```rust
// SF7  → sf_index = 0
// SF8  → sf_index = 1
// SF9  → sf_index = 2
// SF10 → sf_index = 3
// SF11 → sf_index = 4
// SF12 → sf_index = 5
```

Поменять надо **в обоих файлах одновременно** и зашить обе платы — иначе
несоответствие SF, никто никого не слышит.

Если хочешь полный sweep по всем SF — раскомментируй увеличение `sf_index`
в `node_a.rs:284` и установи `next_sf_index = if seq+1 == PINGS_PER_SF { … }
else { sf_index };` (см. конец `for seq` loop). В `node_b.rs` верни таймаут-
ветку с `current_sf_index = (current_sf_index + 1) % SF_TABLE.len()` для
ресинка. Подробности — в коммит-истории.
